# tareas-drawer-app

Aplicacion NativeScript con Angular basada en el template drawer-navigation-ng.

## Ejecutar

    npm install
    ns run android
    ns run ios

## Estructura nueva

- src/app/tareas: modulo de funcionalidad con su submodulo de ruteo
- src/app/core/tareas.service.ts: servicio global inyectado por dependencias
- App_Resources/Android/src/main/res/drawable-*/ic_tareas.png
- App_Resources/iOS/Assets.xcassets/ic_tareas.imageset
